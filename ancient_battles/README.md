# Ancient Battles — miniature 3D battle reconstruction system (experimental)

Status: **first complete episode rendered** (Battle of Marathon, 490 BC: 52.4 s, 1080x1920, 30 fps, full narration).

Stylised 3D "collectible miniature" soldiers, assembled from a historical
equipment library, animated by reusable behaviours over a battle timeline that
is synchronised to the narration. Runs fully locally on CPU (three.js in
headless Chromium + ffmpeg). **No AI model is used in this version** — on-screen
labels therefore say "DIGITAL 3D RECONSTRUCTION", not "AI-generated".

## Layout

| Path | Role |
|---|---|
| `library/equipment.yaml` | every item: date range, cultures, evidence level (attested / reconstruction / uncertain), sources, render part |
| `library/civilizations/*.yaml` | dated unit designs (kit, colour variation, allowed behaviours) per civilization |
| `library/formations.yaml` | formation templates (phalanx, wicker-shield wall …) |
| `library/behaviours.yaml` | behaviour catalogue (implemented in `renderer/src/behaviours.js`) |
| `episodes/<battle>/episode.yaml` | battle, research & fact-check, units, timeline (narration seconds), shots |
| `compile.py` | validates history (dates, cultures, behaviours) → `scene.json`; non-attested items become on-screen notes |
| `renderer/src/parts.js` | geometry factories for each `render.part` (helmets, shields, weapons, clothing) |
| `renderer/src/rig.js` | figure rig (FK legs/torso, 2-bone IK arms, props) |
| `renderer/src/behaviours.js` | march, run, level spears, fight (front/press/rear), shoot cycle, hold wall, command, rout, fall |
| `renderer/src/battle.js` | blocks, paths, follow/wheel, casualties, rout, arrows, dust — pure functions of time |
| `renderer/src/world.js`, `post.js` | terrain/sea/ships/vegetation/light; tilt-shift, grade, grain |
| `renderer/render.mjs` | headless frame renderer + ffmpeg encode (narration excerpt muxed, source MP3 untouched) |
| `tests/` | validator tests (wrong century / wrong civilization are rejected) |

## Commands

```bash
cd ancient_battles/renderer && npm install           # three.js only (21 MB, MIT)
python ancient_battles/compile.py ancient_battles/episodes/marathon-490bc/episode.yaml
node ancient_battles/renderer/render.mjs --scene ancient_battles/episodes/marathon-490bc/scene.json --out projects/marathon-poc/renders/poc --showcase --stills
node ancient_battles/renderer/render.mjs --scene ancient_battles/episodes/marathon-490bc/scene.json --out projects/marathon-poc/renders/poc --anim --workers 2   # legacy PNG path
# production path used for the Marathon episode (resumable 90-frame segments, whole narration muxed, never trimmed):
node ancient_battles/renderer/render.mjs --scene ancient_battles/episodes/marathon-490bc/scene.json --out projects/marathon-poc/renders/final \
  --anim --fast --segment 90 --range final --iscale 0.6667 --samples 0 --cull --lod --shadow 4096 --shadowtype pcfsoft --workers 2 --preset veryfast --crf 14 --name final.mp4
python -m pytest -q ancient_battles/tests
```

## Adding a battle (target workflow)
1. Research → `episode.yaml` `research.claims` (sources, disputed points, decisions).
2. Pick/add dated designs in `library/civilizations/` (new equipment → `equipment.yaml` + a factory in `parts.js` if the shape is new, e.g. scutum, galea, sarissa, elephant).
3. Units, timeline and shots in `episode.yaml`; `compile.py` refuses out-of-period kit.
4. Preview stills (`--stills --shotstills --scale 0.5`), then render.

## Rendering performance (measured, 4 vCPU / 15 GB / no GPU, Chromium SwiftShader)
| Pipeline | Time per 1080x1920 frame | 52.4 s episode (1,572 frames) |
|---|---|---|
| Legacy (`--anim`, 4x MSAA, 4 post passes, PNG screenshots) | 6.85 s | ~3 h (extrapolated) |
| Fast (`--fast`, flags above, 2 workers) | 2.8 s effective (3.7-8.5 s per worker; clash shots slowest) | **73.2 min** render + mux, measured |

Fast path: 720x1280 internal render upscaled in one fused post pass (ACES, tilt-shift, grade, grain);
captions/labels drawn at full 1080x1920; frame culling + LOD for distant soldiers with per-frame
instance compaction; raw frames streamed to ffmpeg. With all switches off the legacy output is
pixel-identical to the original renderer (verified on 6 frames). `scene.json` is generated by
`compile.py` and not committed.

## Known limits (POC)
Figures are simple primitives (no faces, no cloth simulation); motion is
procedural, not motion-captured; formations are illustrative, not to scale;
dense crowds pass through each other in the rout; ~6 s per 1080x1920 frame on
4 CPU cores (SwiftShader). No cavalry/chariot/elephant/standard factories yet.
